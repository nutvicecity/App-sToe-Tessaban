# ท่าคันโท สโตร์ (ต้นแบบ)

เว็บจำลองศูนย์รวมแอปพลิเคชันของเทศบาลตำบลท่าคันโท ทำไว้นำเสนอผู้บริหารให้เห็นภาพรวม

> ⚠️ แอป ยอดดาวน์โหลด คะแนน และรีวิวทั้งหมดเป็น **ข้อมูลจำลอง** ยังไม่มีไฟล์ติดตั้งจริง

## มีอะไรบ้าง
- แอปจำลอง 21 แอป จาก 8 หน่วยงาน (สำนักปลัด, กองคลัง, กองช่าง, การศึกษา, สาธารณสุขฯ, สวัสดิการสังคม, ป้องกันฯ, ผู้บริหาร)
- รองรับ 4 แพลตฟอร์ม: iOS/iPadOS, Android, Windows/macOS และเว็บ
- หน้า "วันนี้" แอปยอดนิยม หมวดตามหน่วยงาน และชั้นแอปสำหรับประชาชนกับเจ้าหน้าที่
- ค้นหาและกรองแอปตามแพลตฟอร์ม กลุ่มผู้ใช้ และหน่วยงาน
- หน้ารายละเอียดของแต่ละแอป มีตัวอย่างหน้าจอทั้งแบบมือถือและคอมพิวเตอร์ ฟีเจอร์ รีวิว และข้อมูลแอป
- ส่วน **ภาพรวมสำหรับผู้บริหาร** แสดงจำนวนแอปตามหน่วยงาน สถานะการพัฒนา ตารางแพลตฟอร์ม และแผนงาน 3 ระยะ
- **เข้าสู่ระบบ:** ปุ่ม "เข้าสู่ระบบ" พาไปที่ระบบล็อกอินกลาง [Log in by Toe](https://github.com/nutvicecity/Log-in-by-Toe) (ไม่มีระบบบัญชีของตัวเองในสโตร์นี้แล้ว)
- **ระบบเจ้าหน้าที่:** ปุ่มและลิงก์ไปที่ https://167-172-66-22.sslip.io/ (เมนูบน, หัวข้อ "สำหรับเจ้าหน้าที่", เมนูบัญชี, หน้าล็อกอิน, ท้ายเว็บ) เปิดในแท็บใหม่
- รองรับโหมดมืดและหน้าจอมือถือ

## วิธีเปิด
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ไฟล์เดียว ไม่ต้องติดตั้งอะไร)
หรือเปิด GitHub Pages ของ repo นี้

ลิงก์ตรงไปยังแอปใดแอปหนึ่งได้ เช่น `index.html#app/ems`

## แก้ไขข้อมูลแอป
ข้อมูลอยู่ในตัวแปร `APPS` และ `DEPTS` ใน `<script>` ท้ายไฟล์ `index.html`

## ระบบบัญชีผู้ใช้และรูปโปรไฟล์

ถอดออกจาก repo นี้แล้ว (เดิมเป็นบัญชีสาธิตที่เก็บในเบราว์เซอร์) ให้ใช้ **ระบบล็อกอินกลาง** ที่ repo
[`Log-in-by-Toe`](https://github.com/nutvicecity/Log-in-by-Toe) แทน ซึ่งมีล็อกอินจริงบนเซิร์ฟเวอร์ รูปโปรไฟล์ (อวตาร์ 20 แบบ/อัปโหลดรูป)
และมีเว็บสโตร์ฉบับเดียวกันนี้รวมอยู่ที่ `/store/` ใช้เซสชันเดียวกัน — **ถ้าจะใช้งานจริงให้ใช้สโตร์ฉบับนั้น** repo นี้เก็บไว้เป็นต้นแบบหน้าตาแบบสถิต
